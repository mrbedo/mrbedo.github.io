# mrbedo.github.io
Bedo Works Of Art

## Adding artwork

Put each work in `src/` as a pair of files with the same name:

- `src/<name>.png` – the image
- `src/<name>.md` – the placard:

```md
# Title
24 × 36 in, oil on canvas

Description of the work.
```

`artworks.json` is generated by GitHub Pages (Jekyll) from the `.png` files in `src/`, so no other changes are needed.
