## Adding artwork

Put each work in `src/` as a pair of files with the same name:

- `src/<name>.jpg` – the image (JPEG and PNG images with lowercase or uppercase extensions are supported)
- `src/<name>.md` – the placard:

```md
# Title
## 2026 Oil on canvas, 24 × 36 in

Description of the work.
```

Markdown heading markers are omitted from the displayed title, year/dimensions line, and description headings.

The viewer displays the placard to the left of the artwork on desktop and below it in the vertical layout on small screens, using larger Palatino-style serif typography. Mobile artwork height is limited to leave room for the text, with scrollable details and bottom navigation controls. Keep the preview server running while browsing: artwork text is fetched when a work is opened, and failed requests display an error with retry instructions.

`artworks.json` is generated by GitHub Pages (Jekyll) from the images in `src/`. Each entry contains the artwork name and its exact image path, preserving the extension and its case, so no other changes are needed.

For local preview, build and serve the site with Jekyll; serving the source files directly does not generate `artworks.json`. Push changes to the branch configured as the GitHub Pages source to update the published website.
